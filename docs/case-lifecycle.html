Linea — Case Lifecycle & Decision Model

How a message moves from intake to audit, and the four decision points where ground truth lives.

allowed / verified path held / unknown path review required high-stakes / at_risk decision point
The four decision points are where your ground truth lives. Everything else is mechanism.

1 · Is it a blocker? Blocker = a currently blocked state that stops progress, not just go-live vocabulary. (Fixes the keyword-biased labels.)
2 · Stakes trigger? Review fires on uncertainty (unknown account) OR stakes (SLA breach, outage, security/compliance, billing dispute, churn/cancellation, VIP account, health→at_risk).
3 · Priority follows the standard impact matrix: P1 blocked/down/many affected · P2 degraded/single-user/workaround exists · P3 minor/informational/future.
4 · Health→at_risk is high-stakes by design: it requires review and is floored so the gates can never auto-promote it back into silent auto-execution.
